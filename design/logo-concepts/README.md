# SmartSync logo concepts

Four alternatives, each in its own folder. Nothing here is wired into the app.

- `01-link/` — **Link**: Two people hooked into one another, making an S.
- `02-fit/` — **Fit**: A circle with one opening, and the one dot that fits it.
- `03-meet/` — **Meet**: Three people leaning in over one table, seen from above.
- `04-together/` — **Together**: Two circles that have met and become one shape.

In each folder:

- `icon.svg`, `icon-dark.svg`, `icon-mono.svg` — the mark alone, 64×64, for light and dark grounds and for one-colour uses
- `logo-horizontal-light.svg`, `logo-horizontal-dark.svg` — mark + wordmark (Plus Jakarta Sans, outlined)
- `wordmark-light.svg`, `wordmark-dark.svg` — the wordmark alone
- `app-icon.svg` — 512×512 rounded tile for app icons
- `favicon.svg` — 32×32 tile for the browser tab
