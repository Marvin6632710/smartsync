# Link — colourways

The same mark in seven colour pairs; see the comparison page. Each folder has icon / icon-dark / icon-mono / app-icon / favicon / logo-horizontal-light / logo-horizontal-dark.

- `indigo-coral/` — Indigo & Coral (Recommended): light #4f46e5 + #e8553a, dark #8b84f3 + #ff8a70
- `ink-indigo/` — Ink & Indigo (Runner-up): light #17130c + #4f46e5, dark #f3ede4 + #8b84f3
- `navy-indigo/` — Navy & Indigo (Tonal, fixed): light #312e81 + #4f46e5, dark #8b84f3 + #c4c0fa
- `indigo-teal/` — Indigo & Teal (Cooler): light #4f46e5 + #0d9488, dark #8b84f3 + #5eead4
- `indigo-ochre/` — Indigo & Ochre (Warmer): light #4f46e5 + #d9690a, dark #8b84f3 + #ffc25c
- `coral-ochre/` — Coral & Ochre (Bold): light #e8553a + #d9690a, dark #ff8a70 + #ffc25c
- `indigo-lilac/` — Indigo & Lilac (As shown before): light #4f46e5 + #8b84f3, dark #a39df6 + #d2cffb
